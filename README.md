## 📁 Структура:

```
.
├── 3D Models/          3D-модели

│   ├── Knob.STL              # Ручка энкодера

```
## 🔌 Электроника и Компоненты

### Список компонентов:
1. **Микроконтроллер:** STM32F103C8T6 (Blue Pill) — 1 шт.
2. **Питание:** Аккумулятор Li-Ion 18650 ( желательно рассчитанный на средний ток ) + Плата зарядки TP4056 или другие — 1 шт.
3. **Дисплей:** 4-разрядный 7-сегментный модуль TM1637 — 1 шт.
4. **Управление:** Инкрементальный энкодер EC11 с тактовой кнопкой — 1 шт.
5. **Адресная лента:** WS2812B (3-5 светодиодов) — 1 шт.
6. **Мощные светодиоды:** 3× 1Вт светодиоды на плате-звездочке (ОБЯЗАТЕЛЬНО С РАДИАТОРОМ!!!!! Иначе расплавится всё! ) — 3 шт.
7. **Ключи управления LED:** MOSFET транзисторы IRLML2502 (или аналоги) — 3 шт.
8. **Делитель АЦП батареи:** Резисторы 100 кОм — 2 шт.
9. **Резисторы затвора:** 100 Ом - 3 шт.
10. **Резисторы подтяжки** 6.2 кОм - 4 шт. ( 3 на затворы и 1 на кнопку энкодера, опционально )

## 📌 Схема подключения (Pinout)
```
Пин STM32 (Blue Pill)   Компонент
─────────────────────────────────────────────────────────────
PA1                 →   АЦП батареи (Vbat / 2)
PA6                 →   WS2812B Data (Подсветка колбы)
PA8                 →   1W LED 1 Gate (ШИМ TIM1_CH1)
PA9                 →   1W LED 2 Gate (ШИМ TIM1_CH2)
PA10                →   1W LED 3 Gate (ШИМ TIM1_CH3)
PB0                 →   Энкодер CLK (EXTI0)
PB1                 →   Энкодер DT (EXTI1)
PB5                 →   TM1637 DIO (Данные дисплея)
PB6                 →   TM1637 CLK (Тактирование дисплея)
PB7                 →   Кнопка энкодера (Active-LOW, EXTI7)
PB13                →   Выход шокера (Active-HIGH)
```
## 🎮 Инструкция по управлению

- **Включение / Пробуждение:** Короткое нажатие на кнопку энкодера во время сна. Пушка плавно зажигает силовые светодиоды и запускает волну в колбе.
- **Выключение / Уход в сон:** Короткое нажатие на кнопку во время работы. Свет плавно гаснет, дисплей отключается, микроконтроллер уходит в глубокий `STOP`-режим.
- **Выбор измерения:** Поворот ручки энкодера меняет значение счётчика (`C000` – `C999`). По умолчанию выставляется измерение **C137**. Значение автосохраняется во Flash.
- **Регулировка яркости силового света (`b 0`–`b10`):** Зажмите кнопку на 1 секунду. На дисплее появится текущий уровень яркости. Вращайте энкодер для изменения.
- **Индикация заряда батареи:** Зажмите кнопку на 2 секунды. Дисплей покажет `bAt`, затем текущий процент заряда (`P100`, `P 85` и т.д.).
- **Секретный режим `-HU-`:** Установите значение счётчика на `111` и зажмите кнопку. Пушка выведет надпись `-HU-` и подаст постоянный логический сигнал `HIGH` на пин `PB13` пока кнопка зажата.
